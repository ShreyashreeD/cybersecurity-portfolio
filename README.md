# Cybersecurity Professional Portfolio

This repository hosts my professional cybersecurity portfolio for **WQE7001 Cyber Security**, showcasing my technical skills, hands-on lab projects, and learning journey.

🌐 **Live Portfolio Website:** [https://github.io](https://github.io)

## Repository Structure
* `index.md` — Main portfolio webpage containing all seven required sections.
* `projects/` — Detailed write-ups and sanitised evidence for my hands-on cybersecurity projects:
  * [Project 1: Network Service Enumeration and Vulnerability Analysis with Nmap](projects/nmap-service-scan/)
  * [Project 2: Network Packet Inspection and Unencrypted HTTP Traffic Analysis with Wireshark](projects/wireshark-traffic-analysis/)
* `_config.yml` — Jekyll site configuration (`minima` theme).
* `.gitignore` — Excludes sensitive credentials, OS metadata, and large VM binaries.
